# Студія — записи та фінанси

PWA-застосунок для манікюрного бізнесу: записи клієнток, послуги з цінами,
автоматичний розрахунок суми, облік витрат і звіти по доходу/прибутку.
Працює на комп'ютері й телефоні, встановлюється як застосунок, має офлайн-режим.

---

## Крок 1. Створити проєкт Firebase (5 хв)

1. Відкрий [console.firebase.google.com](https://console.firebase.google.com) → **Add project** → дай назву (наприклад `nail-studio`) → створи.
2. У лівому меню: **Build → Authentication → Get started → Sign-in method → Email/Password → Enable**.
3. Там же, вкладка **Users → Add user** — створи один акаунт (пошта + пароль), яким твоя дівчина буде входити в застосунок.
4. У лівому меню: **Build → Firestore Database → Create database** → режим **Production** → обери регіон (найближчий, напр. `eur3`).
5. Вкладка **Rules** у Firestore — видали весь текст і встав вміст файлу `firestore.rules` із цього проєкту → **Publish**. Це саме те, що закриває доступ до даних для сторонніх — без входу в акаунт ніхто нічого не прочитає і не запише.
6. На головній сторінці проєкту (значок шестерні → **Project settings**) внизу розділу "Your apps" натисни `</>` (Web app), дай назву, **не** підключай Hosting. Firebase покаже об'єкт `firebaseConfig`.
7. Встав ці значення у файл `src/firebase.js` замість `'ВСТАВ_СЮДИ'`.

## Крок 2. Запустити локально

```bash
npm install
npm run dev
```

Відкриється на `http://localhost:5173`. Увійди тим акаунтом, який створив(-ла) у кроці 1.3.

## Крок 3. Викласти на GitHub Pages (автоматично)

1. Створи новий репозиторій на GitHub — **назви його рівно `nail-studio`** (це вже прописано в `vite.config.js` як base path). Якщо хочеш іншу назву — постав її замість `nail-studio` у рядку `base:` в `vite.config.js` і у `start_url`/`scope` в тому ж файлі.
2. Залий код:
   ```bash
   git init
   git add .
   git commit -m "init"
   git branch -M main
   git remote add origin https://github.com/ТВІЙ_НІК/nail-studio.git
   git push -u origin main
   ```
3. У репозиторії на GitHub: **Settings → Pages → Source → GitHub Actions**. Все, workflow `.github/workflows/deploy.yml` вже налаштований і задеплоїть сайт автоматично при кожному `git push` у `main`.
4. Через 1-2 хв сайт буде доступний на `https://ТВІЙ_НІК.github.io/nail-studio/`.

## Крок 4. Встановити як застосунок на телефон/комп'ютер

- **Android/десктоп Chrome**: відкрити сайт → у меню браузера "Встановити застосунок" / іконка встановлення в адресному рядку.
- **iPhone (Safari)**: відкрити сайт → кнопка "Поділитися" → "На екран Домівки".

Після встановлення застосунок відкривається окремою іконкою, без адресного рядка браузера, і працює офлайн — усі зміни, зроблені без інтернету, збережуться локально і синхронізуються, щойно з'явиться мережа.

## Структура даних

Усі дані лежать у Firestore за шляхом `users/{uid}/...`, де `uid` — це ID акаунту, яким увійшли. Це і є той самий механізм, що робить дані приватними.

- `clients` — ім'я, телефон, день народження, нотатки
- `services` — назва, ціна, тривалість
- `bookings` — запис: клієнтка, дата, час, обрані послуги (знімок ціни на момент запису — щоб зміна прайсу в майбутньому не перераховувала старі звіти), статус, сума
- `expenses` — витрати: назва, сума, дата, категорія

## Що можна додати далі

- Нагадування клієнткам (Telegram-бот)
- Публічне посилання для самозапису клієнток
- Експорт звітів у Excel
- Резервне копіювання в Google Sheets

Повний план і обґрунтування рішень — у файлі `план-манікюр-додаток.md`, який був надісланий окремо в чаті.
